# VR 有载开关吊芯仿真系统 — 核心开发关键评审标的

> 版本：V1.0 MVP｜设备：PICO 4｜引擎：Unreal Engine 5.3+

---

## 一、性能指标（硬性门槛，必须全部达标）

| 评审项 | 指标要求 | 评审方式 |
|--------|----------|----------|
| 帧率稳定性 | PICO 4 设备上稳定 **≥ 72fps**，严防晕动症 | 全场景压力测试，记录帧率曲线 |
| 场景加载时长 | 每个场景加载 **≤ 3 秒** | 11 个场景逐一计时 |
| 碰撞检测精度 | 芯体吊装间隙碰撞响应延迟 **≤ 1 帧** | 专项物理引擎测试 |
| 触觉反馈延迟 | 手柄震动与视觉/音效同步误差 **≤ 50ms** | 多感官同步测试 |

## 二、功能完整性评审（11 个核心场景逐一验收）

| # | 场景 | 必须通过的关键功能点 |
|---|------|----------------------|
| 0 | 系统主厅 | 三模式光门可选（教学/练习/考核）；任务简报 UI 正常显示 |
| 1 | 现场作业准备 | 手势识别判定安全帽/工作服/绝缘鞋；工前会语音识别复述校验；**流程锁**：未完成安全检查无法打开工具柜 |
| 2 | 修前检查与试验 | 变比/直阻测试仪动态数据生成；油样瓶冲洗计数 ≥ 3 次强制校验；修前数据自动写入报告 |
| 3 | 切换与选择开关配合 | 摇把旋转圈数精确计算（2圈 ± 5% 容差）；三层感官反馈（视觉计数器 + 听觉咔哒 + 触觉叩击）同步 |
| 4 | 有载开关放油 | Niagara 油液流动效果；滤油机两段音频（正常抽油/空转）；**顺序判断**：先关阀门再停机，错误操作扣分记录 |
| 5 | 芯体吊出 | 三级碰撞反馈（预警摩擦声 → 晃动停止提示 → 任务失败红色警报）；吊具自检 UI；起吊前安全确认 4 项 |
| 6 | 芯体检查 | 放大镜功能可用；游标卡尺精度 0.02mm；触头行程 L1-L2 ≥ 1.5mm 判定逻辑；故障库注入（≥ 3 种预设故障） |
| 7 | 芯体回装 | 触头行程**二次确认**强制步骤；手动切换测试 ≥ 3 次；动态污渍清洁系统（清洗前后视觉对比） |
| 8 | 芯体复装 | 内窥镜画中画视角切换；芯体导向槽归位感（音频 + 触觉）；档位不一致时系统阻断传动轴安装 |
| 9 | 注油及排气 | 三排气点顺序锁（低→高）；纯气 → 气液混合 → 纯油三阶段视觉变化；内部气体含量隐藏参数清零逻辑 |
| 10 | 电动机构调试 | 手动/电动互锁验证；差数平衡校验圈数比对（示例：33圈）；上下极限双重保护（机械卡死 + 电气按钮失效）；遥调联动后台 UI |
| 11 | 修后试验 | 特性试验波形显示 + 修前/修后并排对比；变比偏差 ≤ ±0.5% 判定；直阻三相互差 ≤ 2% 判定；油样三项指标联动（击穿电压/微水/介损）；**一票否决**逻辑触发 |

## 三、技术架构评审

### 3.1 系统分层完整性

| 层级 | 模块 | 评审要点 |
|------|------|----------|
| 表现层 | VR 头显渲染 | Nanite 高模 + Lumen 全局光照 + Niagara 流体，三项特性均已启用 |
| 应用层 | 流程引擎 | `UTrainingFlowManager` 状态机覆盖全部 11 阶段；流程锁条件配置完整 |
| 应用层 | 评分系统 | `FScoringDimensions` 五维结构体已实现加权算法 |
| 应用层 | 物理交互 | `IToolInteractable` 接口对接所有工具/工件；`Chaos` 吊装约束模拟正常 |
| 数据层 | 资产管理 | 3D 模型"一Actor一文件"组织；故障模型库 ≥ 3 种可配置 |
| 支撑层 | XR 兼容性 | OpenXR 标准适配 PICO 4；Inside-Out 定位与手柄 Haptic 已调通 |

### 3.2 核心技术实现评审要点

**① 智能流程引擎**
- 条件-动作规则库：《安规》条款程序化覆盖率（目标 100% 关键条款）
- 流程锁覆盖所有前置依赖节点，不可绕过

**② 多模态物理交互**
- 游标卡尺：副尺滑动手感 + 0.02mm 精度读数
- 力矩扳手："咔哒"触觉反馈与力矩到达值精确绑定
- 吊装系统：吊带柔体 + 芯体刚体动力学，稳定性实时计算

**③ 智能教练系统（周师傅）**
- 行为树覆盖所有场景的引导、纠错、原理讲解三类事件
- 语音识别模块：工前会关键口令复述识别准确率 ≥ 90%

**④ 操作回放系统**
- `UTimelineComponent` 录制：手部轨迹 + 视角 + 交互事件
- 第三人称回放视角稳定，可定位到具体错误时间点

## 七、V1.0 MVP 专家评审通过条件（综合判定）

> 以下 **全部满足** 方可判定 MVP 通过：

- [ ] 11 个核心场景全流程可无中断运行（教学模式）
- [ ] 帧率全程稳定 ≥ 72fps，无明显掉帧
- [ ] 五维评分系统输出结果与专家人工评分一致率 ≥ 85%
- [ ] 至少 3 种预设故障可被系统正确识别和评分
- [ ] 修前/修后数据对比报告自动完整生成
- [ ] 核心流程锁（安全装备 → 工具准备 → 工前会）不可绕过验证通过
- [ ] 智能教练（周师傅）在所有场景的引导覆盖率 100%
- [ ] 吊装碰撞任务失败机制触发正确，且可从断点恢复练习
