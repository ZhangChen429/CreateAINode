- SmartObject 系统架构
  - 1. 核心组件生命周期流程
    - SmartObjectComponent（场景实例）生命周期
      - 阶段 1: 组件初始化
        - 创建时读取 Definition
          - Definition 资产引用绑定
        - 设置组件的世界变换
          - Transform（位置、旋转、缩放）
        - 初始化启用状态
          - bIsEnabled = true（默认）
        - 组件标记为未注册
          - RegisteredHandle = Invalid
      - 阶段 2: 自动注册到 Subsystem
        - BeginPlay 时触发注册
          - OnWorldComponentsUpdated 事件
        - 调用 Subsystem 注册
          - Subsystem->RegisterSmartObject(this)
        - Subsystem 验证 Definition
          - 检查 Definition 是否有效
          - 检查 Slots 配置是否正确
        - Subsystem 生成 SmartObjectHandle
          - 全局唯一标识符
        - Subsystem 创建 Runtime 数据
          - 创建 FSmartObjectRuntime
          - 初始化所有 RuntimeSlots
          - 添加到 Main Container
        - Subsystem 添加到空间索引
          - SpacePartition->Add(Handle, Transform)
        - 返回注册结果给 Component
          - RegisteredHandle = 新生成的 Handle
      - 阶段 3: 运行时更新
        - Transform 变化时
          - 检测位置/旋转变化
          - 通知 Subsystem 更新
            - Subsystem->UpdateSmartObjectTransform()
          - Subsystem 更新 Runtime.Transform
          - Subsystem 更新空间索引
          - 触发 OnTransformChanged 事件
        - 启用/禁用状态变化时
          - SetEnabled(bNewEnabled)
          - 通知 Subsystem
            - Subsystem->SetSmartObjectEnabled()
          - Subsystem 更新 Runtime.bIsEnabled
          - 如果禁用：中断当前交互
          - 触发 OnSlotEnabled 事件
        - Definition 改变时
          - 先注销当前注册
          - 更新 Definition 引用
          - 重新注册
      - 阶段 4: 组件销毁
        - EndPlay 时触发注销
          - OnWorldComponentsUpdated 事件
        - 调用 Subsystem 注销
          - Subsystem->UnregisterSmartObject(this)
        - Subsystem 清理 Runtime
          - 中断所有活跃交互
          - 释放所有 Claimed/Occupied 的 Slots
          - 从 Main Container 移除
          - 从空间索引移除
        - Component 清理
          - RegisteredHandle = Invalid
    - SmartObjectDefinition（配置资产）设计流程
      - 阶段 1: 创建 Definition 资产
        - 在编辑器创建 Data Asset
          - Content Browser → Create → SmartObjectDefinition
        - 命名 Definition
          - 例如：DA_Chair、DA_Vehicle、DA_Workstation
      - 阶段 2: 配置对象级设置
        - 设置对象级 UserTagFilter
          - 例如：MatchAny("Character.Human", "Character.Robot")
          - 决定哪些类型的 AI 可以使用这个对象
        - 设置对象级 ActivityTags
          - 例如：SmartObject.Furniture, SmartObject.Interactive
          - 用于查询时的标签匹配
        - 设置 UserTags 过滤策略
          - Combine：对象级 + 槽位级（都要满足）
          - Override：槽位级覆盖对象级
        - 配置对象级 WorldConditions
          - 例如：TimeOfDay、WeatherCondition
          - 对象可用的条件
      - 阶段 3: 配置 Slots
        - 添加 Slot 定义
          - Add Slot（可以添加多个）
        - 设置 Slot 的相对变换
          - Offset：相对于对象的位置偏移
            - 例如：车辆驾驶座 (50, 0, 100)
          - Rotation：相对于对象的旋转
            - 例如：朝向车头 (0, 90, 0)
        - 配置入口位置（可选）
          - bUseEntranceLocation = true
          - EntranceLocationOffset：AI 导航的目标位置
            - 例如：车门位置 (100, 50, 0)
          - EntranceRotationOffset：到达时的朝向
        - 设置 Slot 级 UserTagFilter
          - 例如：驾驶座 → "Character.HasDriverLicense"
          - 乘客座 → Empty（无要求）
        - 设置 Slot 级 ActivityTags
          - 例如：Slot 0 → "SmartObject.Drive"
          - 例如：Slot 1 → "SmartObject.Ride"
        - 配置 Slot 级 WorldConditions
          - 例如：AI 身高、体重等要求
      - 阶段 4: 配置 Behavior
        - 选择 BehaviorDefinition 类型
          - GameplayBehaviorSmartObjectBehaviorDefinition
          - GameplayInteractionSmartObjectBehaviorDefinition
          - 自定义 BehaviorDefinition
        - 创建 BehaviorConfig 资产
          - 对于 GameplayBehavior：
            - 创建 GameplayBehaviorConfig
            - 选择 BehaviorClass（具体行为类）
              - 例如：BP_SitBehavior
            - 配置 Parameters
              - 例如：Duration: 5.0, Animation: Anim_Sit
          - 对于 StateTree：
            - 创建 StateTree 资产
            - 配置 States 和转换
        - 将 BehaviorConfig 分配给 Slot
          - Slot.BehaviorDefinitions.Add(Config)
    - SmartObjectRuntime（运行时数据）生命周期
      - 阶段 1: Runtime 创建（注册时）
        - Subsystem 创建 Runtime 实例
          - FSmartObjectRuntime* Runtime = new FSmartObjectRuntime()
        - 生成全局唯一 Handle
          - SmartObjectHandle = HandleGenerator.Generate()
        - 绑定 Definition 引用
          - Runtime.Definition = Component->Definition
        - 复制 Transform
          - Runtime.Transform = Component->GetComponentTransform()
        - 初始化启用状态
          - Runtime.bIsEnabled = Component->IsEnabled()
        - 创建 RuntimeSlots 数组
          - 根据 Definition.Slots.Num() 创建
          - 每个 Slot 初始化为 Free 状态
        - 添加到 Main Container
          - RuntimeSmartObjects.Add(Handle, Runtime)
      - 阶段 2: RuntimeSlot 初始化
        - 为每个 Slot 创建 RuntimeSlot
        - 初始化 Slot 数据
          - SlotHandle = {SmartObjectHandle, SlotIndex}
          - State = Free
          - User = Invalid
          - ClaimedPriority = None
          - bIsEnabled = true
          - UserData = Empty
        - 绑定 Slot Definition
          - 引用对应的 FSmartObjectSlotDefinition
      - 阶段 3: Runtime 状态更新
        - Transform 更新
          - Component Transform 变化时触发
          - Runtime.Transform = 新 Transform
          - 更新空间索引位置
          - 触发 OnTransformChanged 事件
        - 启用状态更新
          - Component 启用/禁用时触发
          - Runtime.bIsEnabled = 新状态
          - 如果禁用：所有 Slots 变为不可用
          - 触发 OnSlotEnabled 事件
        - Slot 状态更新
          - AI Claim 时：Free → Claimed
          - AI Occupy 时：Claimed → Occupied
          - AI Release 时：Occupied/Claimed → Free
      - 阶段 4: Runtime 销毁（注销时）
        - 清理活跃交互
          - 遍历所有 Occupied/Claimed 的 Slots
          - 触发 OnSlotInvalidated 回调
          - 强制释放所有 Slots
        - 从容器移除
          - RuntimeSmartObjects.Remove(Handle)
        - 从空间索引移除
          - SpacePartition->Remove(Handle)
        - 释放 Runtime 内存
          - delete Runtime
  - 2. Subsystem 核心 API 执行流程
    - FindSmartObjects() - 查询流程（9 层过滤）
      - 阶段 1: 接收查询请求
        - 验证输入参数
          - Request.QueryBox 是否有效
          - Request.Filter 是否正确配置
        - 验证 Subsystem 状态
          - bRuntimeInitialized == true
        - 准备输出数组
          - OutResults.Reset()
      - 阶段 2: 空间查询（性能优化）
        - 调用空间分区查询
          - SpacePartition->Find(QueryBox, CandidateHandles)
        - 空间索引快速筛选
          - Octree/HashGrid 结构
          - O(log N) 性能
          - 从 10000 个对象中快速找出 5-10 个候选
        - 返回候选对象 Handle 列表
          - TArray<FSmartObjectHandle> CandidateHandles
      - 阶段 3: 遍历候选对象
        - 对每个候选对象执行详细过滤
          - for (Handle : CandidateHandles)
      - 阶段 4: 对象级过滤
        - 获取 Runtime 数据
          - Runtime = GetRuntimeInstanceInternal(Handle)
        - 精确位置验证
          - QueryBox.IsInside(Runtime.Transform.Location)
        - 过滤层 1: 对象启用状态
          - if (!Runtime.IsEnabled()) → 跳过
        - 过滤层 2: 自定义 Predicate
          - if (!Filter.Predicate(Handle)) → 跳过
        - 继续槽位级过滤
      - 阶段 5: Definition 级槽位过滤
        - 调用槽位过滤函数
          - FindSlotsInternal(Handle, Runtime, Filter, SlotHandles)
        - 获取 Definition
          - Definition = Runtime.GetDefinition()
        - 过滤层 3: 对象级 UserTags
          - 如果 UserTagsFilteringPolicy == Combine
          - if (!Definition.UserTagFilter.Matches(Filter.UserTags)) → 跳过所有槽位
        - 遍历每个 Slot Definition
          - for (i = 0; i < Definition.Slots.Num(); ++i)
        - 过滤层 4: BehaviorDefinition 类型
          - if (Filter.BehaviorDefinitionClasses 不为空)
          - 检查 Slot 是否支持指定的框架类型
          - if (不匹配) → 跳过该槽位
        - 过滤层 5: ActivityTags
          - GetSlotActivityTags(Slot, ActivityTags)
          - if (!Filter.ActivityRequirements.Matches(ActivityTags)) → 跳过
        - 过滤层 6: 槽位级 UserTags
          - SlotUserTagFilter = Slot.GetUserTagFilter()
          - if (!SlotUserTagFilter.Matches(Filter.UserTags)) → 跳过
        - 收集通过 Definition 过滤的槽位索引
          - ValidSlotIndices.Add(i)
      - 阶段 6: 条件上下文设置
        - 创建条件评估上下文
          - FWorldConditionContextData ConditionContext
        - 设置 Schema
          - ConditionContext.SetSchema(Definition.WorldConditionSchema)
        - 绑定 SmartObject 数据
          - SetupConditionContextCommonDataInternal(ConditionContext, Runtime)
        - 绑定 AI 用户数据
          - BindPropertiesFromStructInternal(ConditionContext, UserData)
      - 阶段 7: 对象级条件评估
        - 过滤层 8: 评估对象级 WorldConditions
          - if (Filter.bShouldEvaluateConditions)
          - if (!EvaluateObjectConditions(ConditionContext, Runtime)) → 跳过所有槽位
        - 例如：时间条件、天气条件等
      - 阶段 8: Runtime 槽位状态过滤
        - 遍历通过 Definition 过滤的槽位
          - for (SlotIndex : ValidSlotIndices)
        - 获取 RuntimeSlot
          - RuntimeSlot = Runtime.GetSlot(SlotIndex)
        - 过滤层 7a: 槽位启用状态
          - if (!Filter.bShouldIncludeDisabledSlots && !RuntimeSlot.IsEnabled()) → 跳过
        - 过滤层 7b: 槽位占用状态
          - 检查 RuntimeSlot.State
          - if (State == Free) → ✅ 可用
          - if (State == Claimed && ClaimedPriority < Filter.ClaimPriority) → ✅ 可抢占
          - if (State == Occupied) → ❌ 不可用
          - if (不可用) → 跳过
        - 过滤层 9: 槽位级条件评估
          - SlotHandle = {Handle, SlotIndex}
          - if (Filter.bShouldEvaluateConditions)
          - if (!EvaluateSlotConditions(ConditionContext, Runtime, SlotHandle)) → 跳过
        - 槽位通过所有过滤！
          - SlotHandles.Add(SlotHandle)
      - 阶段 9: 构建返回结果
        - 将槽位添加到结果数组
          - for (SlotHandle : SlotHandles)
            - OutResults.Emplace(Handle, SlotHandle)
        - 返回结果结构
          - FSmartObjectRequestResult { SmartObjectHandle, SlotHandle }
      - 阶段 10: 返回给调用者
        - 返回是否找到结果
          - return (OutResults.Num() > 0)
        - AI 从结果中选择槽位
          - 进入下一阶段：Claim
    - MarkSlotAsClaimed() - 声明流程（Free → Claimed）
      - 阶段 1: 接收声明请求
        - AI 传递参数
          - SlotHandle：要声明的槽位
          - UserData：AI 的信息（Actor、Tags）
          - ClaimPriority：声明优先级
        - 验证输入参数
          - SlotHandle.IsValid()
          - UserData.IsValid()
      - 阶段 2: 获取 Runtime 数据
        - 从 Main Container 查找
          - Runtime = GetRuntimeInstanceInternal(SlotHandle.SmartObjectHandle)
        - 验证 Runtime 有效
          - if (!Runtime) → 返回 InvalidHandle
        - 获取 RuntimeSlot
          - RuntimeSlot = Runtime->GetMutableSlot(SlotHandle.GetSlotIndex())
      - 阶段 3: 验证槽位可声明性
        - 检查槽位启用状态
          - if (!RuntimeSlot.IsEnabled()) → 返回 InvalidHandle
          - if (!Runtime.IsEnabled()) → 返回 InvalidHandle
        - 检查槽位状态
          - if (State == Free) → ✅ 可以声明
          - if (State == Claimed)
            - if (RuntimeSlot.ClaimedPriority < ClaimPriority) → ✅ 可以抢占
            - else → ❌ 优先级不足，返回 InvalidHandle
          - if (State == Occupied) → ❌ 不可声明，返回 InvalidHandle
        - 调用 RuntimeSlot.CanBeClaimed(ClaimPriority)
          - 内部验证所有条件
      - 阶段 4: 生成 UserHandle
        - Subsystem 生成唯一标识
          - UserHandle = UserHandleGenerator.Generate()
        - UserHandle 用于追踪使用者
          - 后续验证 User 身份时使用
      - 阶段 5: 执行 Claim 操作
        - 调用 RuntimeSlot.Claim()
          - RuntimeSlot.Claim(UserHandle, ClaimPriority)
        - RuntimeSlot 内部更新
          - State = Claimed ★
          - User = UserHandle
          - ClaimedPriority = ClaimPriority
        - 验证 Claim 成功
          - if (!bClaimSuccess) → 返回 InvalidHandle
      - 阶段 6: 存储 UserData
        - 保存 AI 的用户数据
          - RuntimeSlot.UserData = FInstancedStruct(UserData)
        - UserData 包含
          - Actor 引用
          - UserTags（如 Character.Male）
          - 其他自定义数据
      - 阶段 7: 构建 ClaimHandle
        - 创建 ClaimHandle
          - ClaimHandle = FSmartObjectClaimHandle(
              SmartObjectHandle,  // 哪个对象
              SlotHandle,         // 哪个槽位
              UserHandle          // 哪个用户
            )
        - ClaimHandle 用于后续操作
          - MarkSlotAsOccupied(ClaimHandle)
          - FindEntranceLocationForSlot(ClaimHandle)
          - MarkSlotAsFree(ClaimHandle)
      - 阶段 8: 触发事件通知
        - 广播 OnSlotChanged 事件
          - OnSlotChangedInternal(Runtime, Slot, SlotHandle, OnClaimed, UserData)
        - 全局监听者收到通知
          - OnSlotChanged.Broadcast(...)
        - Runtime 特定监听者收到通知
          - Runtime.EventDelegate.Broadcast(...)
      - 阶段 9: 记录日志
        - 输出 Claim 成功日志
          - UE_LOG(LogSmartObject, Log, "Claimed slot using handle %s")
        - 可视化日志（VLog）
          - UE_VLOG_LOCATION(..., "Claimed")
      - 阶段 10: 返回 ClaimHandle
        - 返回有效的 ClaimHandle
          - return ClaimHandle
        - AI 验证并保存 ClaimHandle
          - if (ClaimHandle.IsValid())
          - 进入下一阶段：Navigate 或 Occupy
    - FindEntranceLocationForSlot() - 获取入口位置流程
      - 阶段 1: 接收位置查询请求
        - AI 传递参数
          - ClaimHandle：已声明的槽位
          - Request：入口位置请求（包含 UserActor）
        - 验证 ClaimHandle
          - if (!ClaimHandle.IsValid()) → 返回无效结果
      - 阶段 2: 获取 Runtime 和 Slot
        - 从 ClaimHandle 获取 Runtime
          - Runtime = GetRuntimeInstanceInternal(ClaimHandle.SmartObjectHandle)
        - 验证 Runtime
          - if (!Runtime) → Result.bIsValid = false
        - 获取 RuntimeSlot
          - RuntimeSlot = Runtime->GetSlot(ClaimHandle.SlotHandle.GetSlotIndex())
      - 阶段 3: 计算槽位世界变换
        - 获取对象的世界变换
          - ObjectTransform = Runtime->GetTransform()
        - 获取槽位的本地变换
          - SlotDefinition = Definition.GetSlot(SlotIndex)
          - SlotOffset = SlotDefinition.Offset
          - SlotRotation = SlotDefinition.Rotation
        - 计算槽位世界变换
          - SlotWorldTransform = ObjectTransform * SlotLocalTransform
            - 例如：
              - ObjectTransform = (1000, 2000, 0)
              - SlotOffset = (50, 0, 100)
              - SlotWorldTransform = (1050, 2000, 100)
      - 阶段 4: 计算入口位置
        - 检查是否使用自定义入口
          - if (SlotDefinition.bUseEntranceLocation)
        - 方案 A: 使用自定义入口位置
          - EntranceOffset = SlotDefinition.EntranceLocationOffset
          - EntranceRotation = SlotDefinition.EntranceRotationOffset
          - Result.Location = SlotWorldTransform.TransformPosition(EntranceOffset)
          - Result.Rotation = SlotWorldTransform.TransformRotation(EntranceRotation)
            - 例如：
              - 车门位置：EntranceOffset = (100, 50, 0)
              - 最终位置：(1150, 2050, 100)
        - 方案 B: 使用槽位本身位置
          - Result.Location = SlotWorldTransform.GetLocation()
          - Result.Rotation = SlotWorldTransform.GetRotation()
            - 例如：
              - 椅子：直接坐到槽位位置
              - 位置：(1050, 2000, 100)
      - 阶段 5: 标记结果有效
        - 设置结果标志
          - Result.bIsValid = true
      - 阶段 6: 返回位置信息
        - 返回结果结构
          - return FSmartObjectSlotEntranceLocationResult
            {
              Location: FVector(1150, 2050, 100),
              Rotation: FQuat(...),
              bIsValid: true
            }
        - AI 使用位置信息
          - AIMoveTo(Result.Location)
    - MarkSlotAsOccupied() - 占用流程（Claimed → Occupied）
      - 阶段 1: 接收占用请求
        - AI 传递参数
          - ClaimHandle：已声明的槽位
          - BehaviorDefinitionClass：要使用的行为框架类型
        - 验证 ClaimHandle
          - if (!ClaimHandle.IsValid()) → 返回 nullptr
      - 阶段 2: 获取 Runtime 和 Slot
        - 从 ClaimHandle 获取 Runtime
          - Runtime = GetRuntimeInstanceInternal(ClaimHandle.SmartObjectHandle)
        - 验证 Runtime
          - if (!Runtime) → 返回 nullptr
        - 获取 RuntimeSlot
          - RuntimeSlot = Runtime->GetMutableSlot(ClaimHandle.SlotHandle.GetSlotIndex())
      - 阶段 3: 验证槽位可占用性
        - 检查槽位状态
          - if (RuntimeSlot.State != Claimed) → 返回 nullptr
          - 必须是 Claimed 状态才能 Occupy
        - 验证 User 匹配
          - if (RuntimeSlot.User != ClaimHandle.UserHandle) → 返回 nullptr
          - 只有声明者才能占用
        - 验证启用状态
          - if (!RuntimeSlot.IsEnabled()) → 返回 nullptr
          - if (!Runtime.IsEnabled()) → 返回 nullptr
      - 阶段 4: 执行 Occupy 操作
        - 更新槽位状态
          - RuntimeSlot.State = Occupied ★
        - User 和 Priority 保持不变
          - RuntimeSlot.User（不变）
          - RuntimeSlot.ClaimedPriority（不变）
        - 记录占用时间戳（可选）
          - RuntimeSlot.OccupiedTime = CurrentTime
      - 阶段 5: 触发事件通知
        - 广播 OnSlotChanged 事件
          - OnSlotChangedInternal(Runtime, Slot, SlotHandle, OnOccupied, UserData)
        - 通知监听者槽位已被占用
        - 例如：UI 更新、统计记录等
      - 阶段 6: 获取 BehaviorDefinition
        - 从 Definition 获取 Slot 定义
          - SlotDefinition = Definition.GetSlot(SlotIndex)
        - 查找匹配的 BehaviorDefinition
          - BehaviorDef = SlotDefinition.GetBehaviorDefinition<BehaviorDefClass>()
        - 验证 BehaviorDefinition
          - if (!BehaviorDef) → 返回 nullptr
        - BehaviorDefinition 包含
          - 对于 GameplayBehavior：GameplayBehaviorConfig
            - BehaviorClass、Parameters
          - 对于 StateTree：StateTree 资产
      - 阶段 7: 记录日志
        - 输出 Occupy 成功日志
          - UE_LOG(LogSmartObject, Log, "Occupied slot using handle %s")
        - 可视化日志
          - UE_VLOG_LOCATION(..., "Occupied")
      - 阶段 8: 返回 BehaviorDefinition
        - 返回行为定义
          - return BehaviorDefinition
        - AI 使用 BehaviorDefinition
          - 创建 Behavior 实例
          - 触发 Behavior 执行
          - 进入下一阶段：Execute
    - MarkSlotAsFree() - 释放流程（Occupied/Claimed → Free）
      - 阶段 1: 接收释放请求
        - 调用来源
          - GameplayBehavior 自动释放
          - AI Task 完成释放
          - AI 手动释放
          - 异常情况强制释放
        - AI 传递参数
          - ClaimHandle：要释放的槽位
        - 验证 ClaimHandle
          - if (!ClaimHandle.IsValid()) → 返回 false
      - 阶段 2: 获取 Runtime 和 Slot
        - 从 ClaimHandle 获取 Runtime
          - Runtime = GetRuntimeInstanceInternal(ClaimHandle.SmartObjectHandle)
        - 验证 Runtime
          - if (!Runtime) → 返回 false
        - 获取 RuntimeSlot
          - RuntimeSlot = Runtime->GetMutableSlot(ClaimHandle.SlotHandle.GetSlotIndex())
      - 阶段 3: 保存 UserData（用于事件）
        - 保存释放前的 UserData
          - Payload = MoveTemp(RuntimeSlot.UserData)
        - 为什么保存？
          - Release 操作会清空 UserData，但事件通知需要这些信息
      - 阶段 4: 调用 RuntimeSlot.Release()
        - RuntimeSlot 内部验证
          - 验证状态
            - if (State != Claimed && State != Occupied) → 返回 false
            - 只有 Claimed 或 Occupied 才能释放
          - 验证 User 匹配
            - if (RuntimeSlot.User != ClaimHandle.UserHandle) → 返回 false
            - 只有占用者才能释放
          - 处理中断情况（可选）
            - if (bAborted)
            - OnSlotInvalidatedDelegate.ExecuteIfBound(ClaimHandle, State)
        - 执行释放操作
          - bReleased = RuntimeSlot.Release(ClaimHandle, bAborted)
      - 阶段 5: RuntimeSlot 状态清理
        - 重置槽位状态
          - State = Free ★
        - 清空使用者
          - User.Invalidate()
        - 清空用户数据
          - UserData.Reset()
        - 重置优先级
          - ClaimedPriority = None
      - 阶段 6: 触发事件通知
        - 广播 OnSlotChanged 事件
          - OnSlotChangedInternal(Runtime, Slot, SlotHandle, OnReleased, Payload)
        - 全局监听者收到通知
          - 例如：等待该槽位的其他 AI
        - Runtime 特定监听者
          - 例如：UI 更新、统计系统
      - 阶段 7: 记录日志
        - 输出 Release 成功日志
          - UE_LOG(LogSmartObject, Log, "Released using handle %s")

  - 4. Handle 系统生命周期流程
    - FSmartObjectHandle 生成和使用流程
      - 阶段 1: Handle 生成（注册时）
        - Component 注册触发
          - Subsystem->RegisterSmartObject(Component)
        - Subsystem 生成 Handle
          - Handle = SmartObjectHandleGenerator.Generate()
        - Handle 结构
          - 包含全局唯一标识符（通常是递增 ID）
        - 绑定到 Runtime
          - RuntimeSmartObjects.Add(Handle, Runtime)
      - 阶段 2: Handle 存储
        - Component 保存
          - Component->RegisteredHandle = Handle
        - Runtime 保存
          - Runtime->SmartObjectHandle = Handle
        - 空间索引保存
          - SpacePartition->Add(Handle, Transform)
      - 阶段 3: Handle 使用
        - 查询结果中
          - FSmartObjectRequestResult.SmartObjectHandle
        - Claim 时传递
          - 用于定位 Runtime
        - 所有 API 调用
          - GetRuntimeInstanceInternal(Handle)
      - 阶段 4: Handle 失效（注销时）
        - 从容器移除
          - RuntimeSmartObjects.Remove(Handle)
        - 从空间索引移除
          - SpacePartition->Remove(Handle)
        - Component 清空
          - Component->RegisteredHandle = Invalid
    - FSmartObjectSlotHandle 生成和使用流程
      - 阶段 1: SlotHandle 构建
        - 在查询时创建
          - FindSlotsInternal() 中
        - 构建 SlotHandle
          - SlotHandle = FSmartObjectSlotHandle(SmartObjectHandle, SlotIndex)
        - SlotHandle 包含
          - SmartObjectHandle：哪个对象
          - SlotIndex：第几个槽位（0, 1, 2...）
      - 阶段 2: SlotHandle 传递
        - 查询结果中
          - FSmartObjectRequestResult.SlotHandle
        - Claim 时使用
          - MarkSlotAsClaimed(SlotHandle, ...)
        - ClaimHandle 中包含
          - FSmartObjectClaimHandle.SlotHandle
      - 阶段 3: SlotHandle 使用
        - 定位 RuntimeSlot
          - Runtime = GetRuntime(SlotHandle.SmartObjectHandle)
          - Slot = Runtime->GetSlot(SlotHandle.GetSlotIndex())
        - 位置查询
          - GetSlotLocation(SlotHandle)
        - 所有槽位操作
          - 通过 SlotHandle 定位具体槽位
      - 阶段 4: SlotHandle 验证
        - 检查有效性
          - if (SlotHandle.IsValid())
        - 检查索引范围
          - if (SlotIndex < NumSlots)
        - 检查对象存在
          - if (Runtime != nullptr)
    - FSmartObjectUserHandle 生成和使用流程
      - 阶段 1: UserHandle 生成（Claim 时）
        - Subsystem 生成
          - UserHandle = UserHandleGenerator.Generate()
        - 全局唯一标识
          - 每个 AI 每次 Claim 都生成新的 UserHandle
        - 用途
          - 追踪谁在使用/预定槽位
      - 阶段 2: UserHandle 存储
        - RuntimeSlot 保存
          - RuntimeSlot.User = UserHandle
        - ClaimHandle 包含
          - FSmartObjectClaimHandle.UserHandle
      - 阶段 3: UserHandle 验证
        - Occupy 时验证
          - if (RuntimeSlot.User != ClaimHandle.UserHandle)
          - 只有声明者才能占用
        - Release 时验证
          - if (RuntimeSlot.User != ClaimHandle.UserHandle)
          - 只有占用者才能释放
        - 防止非法操作
          - 其他 AI 无法释放别人占用的槽位
      - 阶段 4: UserHandle 清空（Release 时）
        - 槽位释放时
          - RuntimeSlot.User.Invalidate()
        - 变为无效
          - User = Invalid
    - FSmartObjectClaimHandle 完整生命周期
      - 阶段 1: ClaimHandle 构建（Claim 成功后）
        - 组合三个 Handle
          - ClaimHandle = FSmartObjectClaimHandle(
              SmartObjectHandle,  // 哪个对象
              SlotHandle,         // 哪个槽位
              UserHandle          // 哪个用户
            )
        - 绑定关系
          - 明确了"谁在哪个对象的哪个槽位"
      - 阶段 2: ClaimHandle 返回给 AI
        - MarkSlotAsClaimed 返回
          - return ClaimHandle
        - AI 验证
          - if (ClaimHandle.IsValid())
        - AI 保存
          - 用于后续所有操作
      - 阶段 3: ClaimHandle 使用
        - 获取位置
          - FindEntranceLocationForSlot(ClaimHandle)
        - 占用槽位
          - MarkSlotAsOccupied(ClaimHandle)
        - 释放槽位
          - MarkSlotAsFree(ClaimHandle)
        - 所有操作的凭证
          - 验证身份和权限
      - 阶段 4: ClaimHandle 验证
        - 检查整体有效性
          - ClaimHandle.IsValid()
        - 检查各部分
          - SmartObjectHandle.IsValid()
          - SlotHandle.IsValid()
          - UserHandle.IsValid()
        - Subsystem 验证
          - Runtime 是否存在
          - Slot 是否存在
          - User 是否匹配
      - 阶段 5: ClaimHandle 失效
        - Release 后失效
          - ClaimHandle 不应再被使用
        - AI 清空
          - ClaimHandle.Invalidate()
        - 重新使用需要重新 Claim
          - 获得新的 ClaimHandle
  - 5. 状态机转换详细流程
    - Free → Claimed 转换流程
      - 步骤 1: 前置条件检查
        - Slot 当前状态
          - State == Free
        - Slot 启用状态
          - RuntimeSlot.IsEnabled() == true
          - SmartObjectRuntime.IsEnabled() == true
        - 没有其他 User
          - RuntimeSlot.User == Invalid
      - 步骤 2: 执行转换
        - 调用 RuntimeSlot.Claim()
          - Claim(UserHandle, ClaimPriority)
        - 更新状态
          - State = Claimed ★
        - 记录使用者
          - User = UserHandle
        - 记录优先级
          - ClaimedPriority = ClaimPriority
      - 步骤 3: 存储用户数据
        - 保存 AI 信息
          - UserData = FInstancedStruct(AIData)
      - 步骤 4: 触发事件
        - 广播 OnClaimed 事件
          - OnSlotChanged(OnClaimed)
          - 监听者收到通知
    - Claimed → Occupied 转换流程
      - 步骤 1: 前置条件检查
        - Slot 当前状态
          - State == Claimed
        - User 匹配
          - RuntimeSlot.User == ClaimHandle.UserHandle
        - 启用状态
          - IsEnabled() == true
      - 步骤 2: 执行转换
        - 更新状态
          - State = Occupied ★
        - User 和 Priority 保持不变
      - 步骤 3: 触发事件
        - 广播 OnOccupied 事件
          - OnSlotChanged(OnOccupied)
          - 监听者收到通知
      - 步骤 4: 返回 BehaviorDefinition
        - 提供行为配置
          - return BehaviorDefinition
    - Occupied → Free 转换流程
      - 步骤 1: 前置条件检查
        - Slot 当前状态
          - State == Occupied
        - User 匹配
          - RuntimeSlot.User == ClaimHandle.UserHandle
      - 步骤 2: 保存数据（用于事件）
        - 保存 UserData
          - Payload = MoveTemp(UserData)
      - 步骤 3: 执行转换
        - 更新状态
          - State = Free ★
        - 清空使用者
          - User.Invalidate()
        - 清空用户数据
          - UserData.Reset()
        - 重置优先级
          - ClaimedPriority = None
