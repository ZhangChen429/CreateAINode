# 3D可视化标记 - 快速使用指南

## 适用条件
- ✅ 游戏版本：开发版（非Final）
- ✅ 无需MOD
- ✅ 无需重新编译

## 操作步骤

### 1. 打开调试菜单
按键：**F12** 或 **~**

### 2. 启用3D可视化
导航到：
```
Debug Menu
└─ Filters
   └─ AI
      └─ Workspots
         └─ Spots  ← 勾选此项
```

### 3. 在3D世界中查看

将镜头对准使用Workspot的NPC：

```
游戏画面：

    NPC坐在椅子上
       ↓
    🔷 蓝色旋转金字塔标记
       （出现在Workspot点位上方）
```

### 4. 确定Workspot信息

**方法A：结合ImGui面板**
1. 同时启用 `Systems → Workspots → Show ImGui Panel`
2. 在3D世界中看到蓝色标记
3. 在ImGui面板中查找对应的Workspot

**方法B：选择节点（高级）**
1. 瞄准蓝色金字塔标记
2. 按特定按键（可能是 **E** 或其他键）
3. 发送 `NodeSelection` 命令
4. 查看调试信息

## 优势
- ✅ 非常直观，直接在3D世界中看到
- ✅ 精确定位Workspot点位
- ✅ 无需查找EntityID

## 缺点
- ⚠️ 只显示Workspot点位，不直接显示NPC ID
- ⚠️ 需要配合ImGui面板使用才能获取完整信息
- ⚠️ 只在开发版本可用

## 实战示例

**场景**：想知道NPC坐的椅子对应哪个Workspot

**步骤**：
1. 按F12 → `Filters → AI → Workspots → Spots`
2. 将镜头移到NPC处
3. 看到椅子上方出现🔷蓝色金字塔
4. 同时按F12 → `Systems → Workspots → Show ImGui Panel`
5. 在面板中找到对应的Workspot名称

## 代码实现（仅供参考）

```cpp
// workspotDebugger.cpp: 263-291
void Debugger::OnRenderDebug(const RenderDebugContext& context)
{
    // 检查调试过滤器是否启用
    Bool drawWorkspotSelector = false;
    if (const rend::DebugFilterHierarchyNode* node =
        rend::DebugFilterHierarchyNode::FindNode("AI/Workspots/Spots"))
    {
        drawWorkspotSelector = context.debugDrawer.GetMask().Test(node->GetFilter());
    }

    // 如果镜头瞄准了Workspot节点
    if (m_nodeIdLookedAt.IsDefined() && drawWorkspotSelector)
    {
        // 绘制蓝色旋转金字塔
        builder.SetColor(Color::BLUE(200));
        builder.AddSolidPyramid(position, axisX, axisY, axisZ);
    }
}
```

## 组合使用建议

**最佳实践：3D可视化 + ImGui面板**

1. 启用 `Filters → AI → Workspots → Spots`（3D标记）
2. 启用 `Systems → Workspots → Show ImGui Panel`（信息面板）
3. 移动镜头到NPC处，看到蓝色标记
4. 在面板中查看详细信息（EntityID、路径、动画等）

这样可以：
- 用3D标记快速定位
- 用ImGui面板获取详细信息
