## 1. 何时选择哪个系统

### 1.1 决策树

```
开始
  ↓
你的项目是UE5项目吗？
  ├─ 是 → 优先考虑SmartObjects（原生支持）
  │        ↓
  │        需要复杂的NPC表演吗？
  │          ├─ 是 → 为SmartObjects添加Workspot特性
  │          └─ 否 → 直接使用SmartObjects
  │
  └─ 否 → 你的项目是开放世界RPG吗？
            ├─ 是 → 优先考虑Workspot风格
            │        ↓
            │        有足够的开发资源吗？
            │          ├─ 是 → 完整实现Workspot系统
            │          └─ 否 → 简化版Workspot + SmartObjects理念
            │
            └─ 否 → 简单的交互系统即可
                      ↓
                      实现基础的SmartObjects风格
```

### 1.2 场景适配表

| 项目类型 | 推荐方案 | 原因 |
|---------|---------|------|
| **开放世界RPG（类2077）** | Workspot完整实现 | 需要非语言叙事、大量NPC表演 |
| **UE5多人在线游戏** | SmartObjects原生 | 需要多框架协作、服务器同步 |
| **UE5单机动作游戏** | SmartObjects + 简化Idle | 不需要复杂表演，但需要姿态管理 |
| **自研引擎RPG** | Workspot理念 + 简化实现 | 借鉴设计思想，但不必完全复刻 |
| **独立小型项目** | 简化的SmartObjects风格 | 工具链成本低，易于维护 |
| **剧情导向游戏** | Workspot + Scene集成 | 需要时序编排、多Actor同步 |

### 1.3 关键特性需求检查表

```
你需要以下哪些特性？（打勾的越多，越倾向Workspot）

[ ] 复杂的姿态切换（站/坐/蹲/躺）
[ ] 自动防穿模过渡动画
[ ] 指数级行为组合（10个动画 → 1000种行为）
[ ] 与Scene/Timeline系统深度集成
[ ] 道具系统（idle变化时自动生成/销毁）
[ ] NPC"表演"而非简单"站位"
[ ] 非语言叙事需求

你需要以下哪些特性？（打勾的越多，越倾向SmartObjects）

[ ] 框架无关（支持StateTree、GAS、自定义系统）
[ ] 多原因启用状态管理
[ ] World Conditions集成
[ ] 编辑器可视化工具链
[ ] 类型安全的Handle系统
[ ] 空间分割查询优化
[ ] 多人游戏网络同步

特殊情况：

[ ] 两种特性都需要 → 融合方案（见第2节）
[ ] 预算和时间有限 → 简化版（见第3节）
```

```cpp
UCLASS(BlueprintType, EditInlineNew)
class UWorkspotBehaviorDefinition : public USmartObjectBehaviorDefinition
{
    GENERATED_BODY()

public:
    // Workspot数据（使用UE的Asset系统）
    UPROPERTY(EditAnywhere, Category = "Workspot")
    TObjectPtr<UWorkspotTreeAsset> WorkspotTree;

    // Idle状态管理
    UPROPERTY(EditAnywhere, Category = "Idle")
    FName RequiredIdle;  // 要求的当前idle（如"stand"）

    UPROPERTY(EditAnywhere, Category = "Idle")
    FName ResultingIdle;  // 执行后的idle（如"sit"）

    // 过渡动画映射
    UPROPERTY(EditAnywhere, Category = "Idle")
    TMap<FString, TObjectPtr<UAnimMontage>> TransitionMontages;
    // Key格式："stand__2__sit"

    // 道具配置
    UPROPERTY(EditAnywhere, Category = "Props")
    TArray<FWorkspotPropDefinition> Props;
};

class UWorkspotTreeAsset : public UDataAsset

public:

// 3. Entry接口（UE风格）
// ==========================================
USTRUCT()
struct FWorkspotEntryBase
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere)
    FName IdleAnim;

    UPROPERTY(EditAnywhere)
    uint32 Flags;

    // 纯虚方法（通过继承实现）
    virtual void Execute(FWorkspotContext& Context) PURE_VIRTUAL(FWorkspotEntryBase::Execute,);
};

// Entry类型
USTRUCT()
struct FWorkspotAnimClip : public FWorkspotEntryBase
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere)
    TObjectPtr<UAnimMontage> Montage;

    UPROPERTY(EditAnywhere)
    float BlendInTime = 0.3f;

    void Execute(FWorkspotContext& Context) override
    {
        Context.PlayMontage(Montage, BlendInTime);
    }
};

USTRUCT()
struct FWorkspotSequence : public FWorkspotEntryBase
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere, Instanced)
    TArray<FInstancedStruct> Children;  // 存储其他Entry

    UPROPERTY(EditAnywhere)
    bool bLoopInfinitely = false;

    void Execute(FWorkspotContext& Context) override
    {
        do {
            for (const FInstancedStruct& Child : Children)
            {
                if (const FWorkspotEntryBase* Entry = Child.GetPtr<FWorkspotEntryBase>())
                {
                    Entry->Execute(Context);
                }
            }
        } while (bLoopInfinitely && !Context.ShouldStop());
    }
};

USTRUCT()
struct FWorkspotSelector : public FWorkspotEntryBase
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere, Instanced)
    TArray<FInstancedStruct> Children;

    UPROPERTY(EditAnywhere)
    TArray<float> Weights;

    void Execute(FWorkspotContext& Context) override
    {
        // 选择逻辑
        int32 SelectedIndex = ChooseWeighted(Weights);
        const FInstancedStruct& Selected = Children[SelectedIndex];

        if (const FWorkspotEntryBase* Entry = Selected.GetPtr<FWorkspotEntryBase>())
        {
            // IdleGuard检查
            FName NewIdle = Entry->IdleAnim;
            if (Context.CurrentIdle != NewIdle)
            {
                // 播放过渡动画
                PlayTransition(Context.CurrentIdle, NewIdle, Context);
                Context.CurrentIdle = NewIdle;
            }

            Entry->Execute(Context);
        }
    }

private:
    void PlayTransition(FName FromIdle, FName ToIdle, FWorkspotContext& Context)
    {
        FString TransitionKey = FromIdle.ToString() + "__2__" + ToIdle.ToString();
        if (UAnimMontage* TransitionMontage = Context.FindTransitionMontage(TransitionKey))
        {
            Context.PlayMontage(TransitionMontage, 0.3f);
            Context.WaitForMontageEnd();
        }
    }
};

// ==========================================
// 4. 执行上下文
// ==========================================
struct FWorkspotContext
{
    AActor* User;
    UAnimInstance* AnimInstance;
    FName CurrentIdle;
    UWorkspotBehaviorDefinition* BehaviorDef;
    bool bStopRequested = false;

    void PlayMontage(UAnimMontage* Montage, float BlendInTime)
    {
        if (User && Montage)
        {
            User->PlayAnimMontage(Montage, 1.0f, NAME_None);
        }
    }

    void WaitForMontageEnd()
    {
        // 等待Montage播放完成（可通过Delegate或轮询）
        if (AnimInstance)
        {
            while (AnimInstance->IsAnyMontagePlaying() && !bStopRequested)
            {
                FPlatformProcess::Sleep(0.1f);
            }
        }
    }

    UAnimMontage* FindTransitionMontage(const FString& Key)
    {
        if (BehaviorDef)
        {
            return BehaviorDef->TransitionMontages.FindRef(Key);
        }
        return nullptr;
    }

    bool ShouldStop() const { return bStopRequested; }
};

// ==========================================
// 5. 使用示例
// ==========================================
void UseWorkspotSmartObject(AActor* User, FSmartObjectClaimHandle ClaimHandle)
{
    USmartObjectSubsystem* Subsystem = GetWorld()->GetSubsystem<USmartObjectSubsystem>();

    // 获取Workspot Behavior
    const UWorkspotBehaviorDefinition* WorkspotBehavior =
        Subsystem->MarkSlotAsOccupied<UWorkspotBehaviorDefinition>(ClaimHandle);

    if (!WorkspotBehavior || !WorkspotBehavior->WorkspotTree)
    {
        return;
    }

    // 创建执行上下文
    FWorkspotContext Context;
    Context.User = User;
    Context.AnimInstance = User->FindComponentByClass<USkeletalMeshComponent>()->GetAnimInstance();
    Context.CurrentIdle = GetCurrentIdleForActor(User);  // 从Actor组件获取
    Context.BehaviorDef = const_cast<UWorkspotBehaviorDefinition*>(WorkspotBehavior);

    // 检查Idle过渡
    if (Context.CurrentIdle != WorkspotBehavior->RequiredIdle)
    {
        // 播放过渡动画
        FString TransitionKey = Context.CurrentIdle.ToString() + "__2__" + WorkspotBehavior->RequiredIdle.ToString();
        if (UAnimMontage* TransitionMontage = WorkspotBehavior->TransitionMontages.FindRef(TransitionKey))
        {
            Context.PlayMontage(TransitionMontage, 0.3f);
            Context.WaitForMontageEnd();
        }
        Context.CurrentIdle = WorkspotBehavior->RequiredIdle;
    }

    // 执行Workspot树
    if (const FWorkspotEntryBase* RootEntry = WorkspotBehavior->WorkspotTree->RootEntry.GetPtr<FWorkspotEntryBase>())
    {
        RootEntry->Execute(Context);
    }

    // 设置结果Idle
    SetCurrentIdleForActor(User, WorkspotBehavior->ResultingIdle);

    // 释放槽位
    Subsystem->MarkSlotAsFree(ClaimHandle);
}
```

### 2.4 道具系统集成

```cpp
// ==========================================
// 道具定义
// ==========================================
USTRUCT()
struct FWorkspotPropDefinition
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere)
    FName PropID;  // "coffee_cup"

    UPROPERTY(EditAnywhere)
    TObjectPtr<UStaticMesh> PropMesh;

    UPROPERTY(EditAnywhere)
    FName AttachSocket;  // "hand_r"

    UPROPERTY(EditAnywhere)
    EWorkspotPropSpawnPolicy SpawnPolicy;
    // OnIdleEnter, OnIdleExit, OnAnimEvent
};

UENUM()
enum class EWorkspotPropSpawnPolicy : uint8
{
    OnIdleEnter,     // 进入特定idle时生成
    OnIdleExit,      // 离开特定idle时销毁
    OnAnimNotify,    // 动画通知时生成/销毁
    Manual           // 手动控制
};

// ==========================================
// 道具管理器组件
// ==========================================
UCLASS()
class UWorkspotPropManagerComponent : public UActorComponent
{
    GENERATED_BODY()

public:
    // 当前生成的道具
    UPROPERTY(Transient)
    TMap<FName, TObjectPtr<UStaticMeshComponent>> ActiveProps;

    void OnIdleChanged(FName OldIdle, FName NewIdle, const TArray<FWorkspotPropDefinition>& Props)
    {
        for (const FWorkspotPropDefinition& Prop : Props)
        {
            if (Prop.SpawnPolicy == EWorkspotPropSpawnPolicy::OnIdleEnter)
            {
                // 检查是否需要生成
                if (ShouldSpawnForIdle(Prop, NewIdle))
                {
                    SpawnProp(Prop);
                }
            }

            if (Prop.SpawnPolicy == EWorkspotPropSpawnPolicy::OnIdleExit)
            {
                // 检查是否需要销毁
                if (ShouldDespawnForIdle(Prop, OldIdle))
                {
                    DespawnProp(Prop.PropID);
                }
            }
        }
    }

    void SpawnProp(const FWorkspotPropDefinition& Prop)
    {
        if (ActiveProps.Contains(Prop.PropID))
        {
            return;  // 已存在
        }

        AActor* Owner = GetOwner();
        USkeletalMeshComponent* Mesh = Owner->FindComponentByClass<USkeletalMeshComponent>();

        if (Mesh && Prop.PropMesh)
        {
            UStaticMeshComponent* PropComp = NewObject<UStaticMeshComponent>(Owner);
            PropComp->SetStaticMesh(Prop.PropMesh);
            PropComp->AttachToComponent(Mesh, FAttachmentTransformRules::SnapToTargetIncludingScale, Prop.AttachSocket);
            PropComp->RegisterComponent();

            ActiveProps.Add(Prop.PropID, PropComp);

            UE_LOG(LogWorkspot, Log, TEXT("Spawned prop: %s"), *Prop.PropID.ToString());
        }
    }

    void DespawnProp(FName PropID)
    {
        if (UStaticMeshComponent* PropComp = ActiveProps.FindRef(PropID))
        {
            PropComp->DestroyComponent();
            ActiveProps.Remove(PropID);

            UE_LOG(LogWorkspot, Log, TEXT("Despawned prop: %s"), *PropID.ToString());
        }
    }
};
```

## 3. 从Workspot迁移到SmartObjects

### 3.1 迁移策略

```
迁移场景：你有一个使用Workspot的项目，想迁移到UE5

策略1：完全重写（推荐用于新项目）
  • 用SmartObjects替代Workspot基础设施
  • 用UWorkspotBehaviorDefinition保留Entry组合逻辑
  • 用StateTree/GAS替代部分复杂行为
  • 时间：3-6个月

策略2：渐进式迁移（推荐用于已有项目）
  • 保留Workspot核心代码
  • 添加SmartObjects的优秀特性（多原因禁用、World Conditions）
  • 新内容使用SmartObjects风格
  • 时间：持续进行

策略3：混合共存（推荐用于大型项目）
  • Workspot用于剧情场景
  • SmartObjects用于开放世界交互
  • 两者通过统一接口桥接
  • 时间：1-2个月桥接层
```

### 3.2 数据迁移工具

```cpp
// ==========================================
// 自动转换工具
// ==========================================
class FWorkspotToSmartObjectConverter
{
public:
    // 转换WorkspotTree到UE资产
    UWorkspotTreeAsset* ConvertWorkspotTree(const work::WorkspotTree& SourceTree)
    {
        UWorkspotTreeAsset* NewAsset = NewObject<UWorkspotTreeAsset>();

        // 转换Root Entry
        NewAsset->RootEntry = ConvertEntry(SourceTree.m_rootEntry);

        // 转换动画
        for (const auto& AnimEntry : SourceTree.m_finalAnimsets)
        {
            UAnimSequence* AnimSeq = ImportAnimation(AnimEntry);
            NewAsset->Animations.Add(AnimSeq);
        }

        // 转换过渡动画
        for (const auto& Transition : SourceTree.m_customTransitionAnims)
        {
            FTransitionAnimDefinition TransDef;
            TransDef.FromIdle = Transition.m_fromIdle;
            TransDef.ToIdle = Transition.m_toIdle;
            TransDef.TransitionAnim = ImportAnimation(Transition.m_transitionAnim);
            NewAsset->CustomTransitions.Add(TransDef);
        }

        return NewAsset;
    }

    FInstancedStruct ConvertEntry(const THandle<IEntry>& SourceEntry)
    {
        if (!SourceEntry.IsValid())
        {
            return FInstancedStruct();
        }

        // 根据类型转换
        if (const AnimClip* Clip = Cast<AnimClip>(SourceEntry.Get()))
        {
            FWorkspotAnimClip NewClip;
            NewClip.IdleAnim = Clip->m_idleAnim;
            NewClip.Montage = ImportAnimationAsMontage(Clip->m_animName);
            NewClip.BlendInTime = Clip->m_blendTime;
            return FInstancedStruct::Make(NewClip);
        }
        else if (const Sequence* Seq = Cast<Sequence>(SourceEntry.Get()))
        {
            FWorkspotSequence NewSeq;
            NewSeq.IdleAnim = Seq->m_idleAnim;
            NewSeq.bLoopInfinitely = Seq->m_loopInfinitely;

            for (const THandle<IEntry>& Child : Seq->m_list)
            {
                NewSeq.Children.Add(ConvertEntry(Child));
            }

            return FInstancedStruct::Make(NewSeq);
        }
        else if (const Selector* Sel = Cast<Selector>(SourceEntry.Get()))
        {
            FWorkspotSelector NewSel;
            NewSel.IdleAnim = Sel->m_idleAnim;
            NewSel.Weights = Sel->m_weights;

            for (const THandle<IEntry>& Child : Sel->m_list)
            {
                NewSel.Children.Add(ConvertEntry(Child));
            }

            return FInstancedStruct::Make(NewSel);
        }

        // 其他类型...
        return FInstancedStruct();
    }

    // 批量转换场景中的Workspot
    void ConvertSceneWorkspots(const FString& ScenePath)
    {
        // 加载场景资源
        ULevelSequence* Sequence = LoadObject<ULevelSequence>(nullptr, *ScenePath);

        // 查找所有Workspot引用
        TArray<FWorkspotReference> WorkspotRefs = FindWorkspotReferences(Sequence);

        for (const FWorkspotReference& Ref : WorkspotRefs)
        {
            // 创建对应的SmartObject Definition
            USmartObjectDefinition* SmartObjDef = CreateSmartObjectDefinition(Ref);

            // 替换引用
            ReplaceWorkspotReference(Sequence, Ref, SmartObjDef);
        }

        // 保存修改后的序列
        Sequence->MarkPackageDirty();
    }

private:
    USmartObjectDefinition* CreateSmartObjectDefinition(const FWorkspotReference& Ref)
    {
        USmartObjectDefinition* SmartObjDef = NewObject<USmartObjectDefinition>();

        // 创建槽位
        FSmartObjectSlotDefinition Slot;

        // 转换Workspot为Behavior
        UWorkspotBehaviorDefinition* Behavior = NewObject<UWorkspotBehaviorDefinition>();
        Behavior->WorkspotTree = ConvertWorkspotTree(*Ref.WorkspotTree);

        Slot.BehaviorDefinitions.Add(Behavior);
        SmartObjDef->Slots.Add(Slot);

        return SmartObjDef;
    }
};

// ==========================================
// 使用示例
// ==========================================
void MigrateProject()
{
    FWorkspotToSmartObjectConverter Converter;

    // 转换所有Workspot资源
    TArray<FString> WorkspotPaths = FindAllWorkspotAssets();

    for (const FString& Path : WorkspotPaths)
    {
        work::WorkspotTree* SourceTree = LoadWorkspotTree(Path);
        UWorkspotTreeAsset* NewAsset = Converter.ConvertWorkspotTree(*SourceTree);

        // 保存为UE资产
        FString NewPath = Path.Replace(TEXT(".workspot"), TEXT("_WS.uasset"));
        SaveAsset(NewAsset, NewPath);

        UE_LOG(LogTemp, Log, TEXT("Converted: %s -> %s"), *Path, *NewPath);
    }

    // 转换场景
    TArray<FString> ScenePaths = FindAllSceneAssets();
    for (const FString& ScenePath : ScenePaths)
    {
        Converter.ConvertSceneWorkspots(ScenePath);
        UE_LOG(LogTemp, Log, TEXT("Converted scene: %s"), *ScenePath);
    }

    UE_LOG(LogTemp, Log, TEXT("Migration completed!"));
}
```

```cpp
{
    GENERATED_BODY()

public:
    // 当前Idle状态
    UPROPERTY(BlueprintReadOnly, Category = "Idle")
    FName CurrentIdle = "stand";

    // 上一次的Idle（用于过渡检测）
    UPROPERTY()
    FName PreviousIdle = "stand";

    // Idle变化事件
    DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FOnIdleChanged, FName, OldIdle, FName, NewIdle);
    UPROPERTY(BlueprintAssignable, Category = "Idle")
    FOnIdleChanged OnIdleChanged;

    // 设置新Idle
    UFUNCTION(BlueprintCallable, Category = "Idle")
    void SetIdle(FName NewIdle)
    {
        if (CurrentIdle != NewIdle)
        {
            PreviousIdle = CurrentIdle;
            CurrentIdle = NewIdle;

            OnIdleChanged.Broadcast(PreviousIdle, CurrentIdle);
        }
    }

    // 获取当前Idle
    UFUNCTION(BlueprintPure, Category = "Idle")
    FName GetCurrentIdle() const { return CurrentIdle; }
};
```

```cpp
UCLASS()
class UTransitionAnimManager : public UWorldSubsystem
{
    GENERATED_BODY()

public:
    // 过渡动画映射
    UPROPERTY()
    TMap<FString, TObjectPtr<UAnimMontage>> TransitionMontages;

    // 注册过渡动画
    UFUNCTION(BlueprintCallable, Category = "Transition")
    void RegisterTransition(FName FromIdle, FName ToIdle, UAnimMontage* Montage)
    {
        FString Key = GetTransitionKey(FromIdle, ToIdle);
        TransitionMontages.Add(Key, Montage);
    }

    // 播放过渡动画
    UFUNCTION(BlueprintCallable, Category = "Transition")
    bool PlayTransition(AActor* User, FName FromIdle, FName ToIdle)
    {
        FString Key = GetTransitionKey(FromIdle, ToIdle);
        if (UAnimMontage* Montage = TransitionMontages.FindRef(Key))
        {
            User->PlayAnimMontage(Montage);
            return true;
        }

        UE_LOG(LogTemp, Warning, TEXT("Missing transition: %s"), *Key);
        return false;
    }

private:
    FString GetTransitionKey(FName FromIdle, FName ToIdle) const
    {
        return FromIdle.ToString() + "__2__" + ToIdle.ToString();
    }
};

// 在Behavior执行时自动处理
void ExecuteSmartObjectWithIdleCheck(AActor* User, UWorkspotBehaviorDefinition* Behavior)
{
    UIdleStateComponent* IdleComp = User->FindComponentByClass<UIdleStateComponent>();
    UTransitionAnimManager* TransitionMgr = GetWorld()->GetSubsystem<UTransitionAnimManager>();

    if (IdleComp && TransitionMgr)
    {
        FName CurrentIdle = IdleComp->GetCurrentIdle();
        FName RequiredIdle = Behavior->RequiredIdle;

        if (CurrentIdle != RequiredIdle)
        {
            // 播放过渡动画
            if (TransitionMgr->PlayTransition(User, CurrentIdle, RequiredIdle))
            {
                // 等待Montage完成
                WaitForMontageEnd(User);
            }

            // 更新Idle状态
            IdleComp->SetIdle(RequiredIdle);
        }
    }

    // 执行Behavior
    ExecuteWorkspotBehavior(User, Behavior);
}
```

## 6. 常见问题解答

### Q1: 我应该从头实现Workspot还是使用SmartObjects？

**A**: 取决于你的引擎和项目类型。

- **UE5项目** → 使用SmartObjects + 添加Workspot特性
- **自研引擎RPG** → 实现Workspot风格，借鉴SmartObjects的优秀设计
- **小型项目** → 简化的SmartObjects风格即可

### Q2: Entry组合模式太复杂了，有简化版吗？

**A**: 可以只实现基础的3种Entry：

```cpp
// 简化版：只需3种Entry
1. AnimClip（叶子节点）
2. Sequence（顺序容器）
3. RandomList（随机容器）

// 省略：
- Selector（姿态选择，可用AnimBP状态机替代）
- ReactionSequence（反应系统，可用通知事件替代）
- TagNode（复用，可用继承替代）
```

### Q3: IdleGuard是否是必须的？

**A**: 不是必须，但强烈推荐。

**不实现IdleGuard的替代方案**：
- 使用AnimBP的状态机处理姿态切换
- 在Behavior内部手动配置过渡动画
- 使用StateTree的过渡状态

**问题**：
- 维护成本高（每个Behavior都要配置）
- 容易遗漏导致穿模
- 无法自动化
