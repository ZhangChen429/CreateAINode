

# CurveScribe 迭代方向及周期评估
（注：本评估为初步规划，不保证无卡点业务，具体落地需结合开发排期、技术难点动态调整）

1.  **CurveAssetData 资产稳定性增强**   P0 长周期 长周期需要快速迭代
    优化曲线资产在编辑、保存、加载及参数同步全流程的数据一致性与稳定性，完善数据校验与版本兼容机制，避免数据丢失或异常错乱。对非必要高频更新场景做同步策略优化，减少无效刷新。

    功能优化需依赖美术测试反馈，未及时收集美术使用中的稳定性痛点，可能导致迭代方向偏差，影响开发价值。

2.  **曲线半径参数实时同步体验优化**   P0 0.5D 长周期需要快速迭代
    修复多控制点、多视口、多编辑模式下曲线半径/宽度参数不同步问题，实现参数修改后全局实时生效、所见即所得，消除状态不一致与操作延迟。

    美术测试是发现同步异常、卡顿等体验问题的核心渠道，未充分开展美术测试，可能遗漏关键痛点，导致优化不彻底，影响美术实际使用效率。

3.  **曲线采样扰动升级：随机偏移升级为程序化噪声偏移** P0 0.5D 
    将离散随机偏转优化为连续自然的程序化噪声扰动，提升镜头运动的流畅度与真实感；支持强度、频率、维度等参数可调，满足不同风格化拍摄需求。


4.  **随机种子模块化独立管理** P1 0.5D 简单
    把随机种子从扰动逻辑中独立为可配置项，支持固定种子复现、自动随机生成、多层扰动独立控种，提升效果可复现性与创作可控性。

    **种子配置的易用性、效果复现的准确性，需通过美术测试验证，美术的实际使用反馈的是功能迭代的核心方向，避免出现 “技术可行但美术用起来不便” 的问题。**

5.  **资产快捷转换能力：选中点位一键生成CurveScribe资产**  P0 0.5D 简单
    优化资产加载与解析流程，面向美术提供一键转换能力：在编辑器中选中任意点位数据，可快速批量生成标准CurveScribe曲线资产，降低创作门槛，提升内容搭建效率。
    **该功能核心服务于美术用户，转换效率、兼容性、资产规范性均需通过美术测试验证，美术的测试反馈是优化转换逻辑、解决卡点的核心需求来源，直接决定功能的实际使用价值。**

6.  **SceneComponent 与 CurveDataAsset 职责解耦** P0 长周期稳定性 
    重构运行时挂载逻辑与纯数据资产的边界，实现数据层与组件层分离，使曲线资产可脱离场景独立编辑、独立复用，提升架构灵活性与资产通用性。
    
7.  **编辑器视口Viewport交互体系建设** P1.5 优先保证 2D
    构建CurveScribe专属3D视口交互体系，统一视口内拾取、绘制、拖拽、预览规则，提供直观可控的空间编辑体验，强化编辑效率与操作一致性。
    **视口交互的易用性、操作流畅度是美术编辑的核心诉求，美术测试反馈是调整交互规则、优化操作体验的唯一依据，直接决定视口交互体系的迭代方向与落地价值。**
8.  **视口Slate交互与DataAsset数据深度绑定** P0 长周期需要快速迭代
    实现编辑器视口交互、实时绘制与DataAsset数据双向同步，所有视口操作直接映射资产变化，无需手动刷新，真正达成所见即所得的编辑体验。

9.  **Actor创建工厂模式统一管理**  P1.5 独立成为生成器价值很大
    采用工厂模式重构CurveScribe相关Actor的创建、初始化与生命周期管理，提升扩展性与维护性，支持多类型Actor动态扩展与统一调度。


10. **基于资产掩码的高效检索与批量管理** P2 资产管线建设长期任务
    提供资产掩码查询能力，支持按标签、类型、参数范围、用途等条件快速筛选曲线资产，实现批量管理与快速定位，提升资产管理效率。

11. **FormScribe** P1.5 PCG迭代方向
    核心聚焦PCG（程序化内容生成）方向，优先实现场景外围包围体功能，完成场景复杂Mesh的轻量化抽象，生成基础代理几何边界；同步规划视觉权重分析、空间约束联动等后续迭代方向，为CurveScribe提供空间感知支撑。
。

美术测试迭代与需求反馈，是本次 UE 编辑器功能（CurveScribe、FormScribe）迭代的重要输入来源，也是规划迭代节奏、合理调整优先级的关键参考依据，同时也是美术生产管线自动化落地的重要验证环节。
各项功能开发与优化，建议紧密结合美术实际使用场景与测试反馈进行推进，并与管线自动化建设目标保持一致，避免脱离实际使用的纯技术迭代。
后续需持续完善美术测试机制与反馈收集流程，通过真实使用验证功能在自动化管线中的适配性与易用性，确保迭代更贴近生产实际、有效解决美术创作中的实际问题，减少无效投入与方向偏差，稳步提升内容生产工业化与自动化水平。
